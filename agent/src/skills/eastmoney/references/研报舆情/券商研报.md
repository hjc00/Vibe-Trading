## 券商研报 + 一致预期 EPS（Research Reports）

工具：`get_research_reports`（`src.tools.research_reports_tool.ResearchReportsTool`）
描述：两路东财免费免鉴权披露拼成一个信封：
- **东财 reportapi** —— A 股滚动券商研报列表：标题、发布机构、分析师、发布日、机构评级标签、该机构的分年度 EPS / PE 预测。主源，驱动 `reports` 块。
- **东财 datacenter**（`datacenter-web`，report `RPT_WEB_RESPREDICT`）—— 市场*一致预期* EPS（分析师估计均值），按前瞻财年。该块为 best-effort：datacenter 失败时 `consensus_eps` 降级为空列表，不中断研报抓取。
市场：仅 A 股（.SH / .SZ / .BJ）。
限速：两路均经东财 `eastmoney` bucket per-host 节流。

<br>

**端点**

| 块 | 端点 URL |
| ---- | -------- |
| reports（东财） | `https://reportapi.eastmoney.com/report/list` |
| consensus_eps（东财 datacenter） | `https://datacenter-web.eastmoney.com/api/data/v1/get` |

<br>

**输入参数（工具入参）**

名称 | 类型 | 必选 | 描述
---- | ---- | ---- | ----
code | str | Y | `<code>.<exchange>`，后缀 SH / SZ / BJ（如 `600519.SH`）。
limit | int | N | 返回最近研报数上限（1–50，默认 20）。

<br>

**端点查询参数**

reportapi：`code=<裸代码>`、`qType=0`（个股研报）、`pageSize=<limit>`、`pageNo=1`。
datacenter：`reportName=RPT_WEB_RESPREDICT`、`columns=ALL`、`filter=(SECURITY_CODE="<裸代码>")`、`pageNumber=1`、`pageSize=1`、`source=WEB`、`client=WEB`。

<br>

**返回字段**

reports（源字段 → 输出键）：

源字段 | 输出键 | 描述
---- | ---- | ----
title | title | 研报标题
orgSName / orgName | brokerage | 发布机构（简称优先）
researcher | analyst | 分析师
publishDate | publish_date | 发布日（取 `YYYY-MM-DD`）
emRatingName / sRatingName | rating | 机构评级
predictThisYearEps / predictNextYearEps | eps_forecast.this_year / .next_year | 分年度 EPS 预测
predictThisYearPe / predictNextYearPe | pe_forecast.this_year / .next_year | 分年度 PE 预测

consensus_eps（东财 datacenter，单行含 `YEAR1..YEAR4` / `EPS1..EPS4`，各配 `YEAR_MARK1..4` 标记）：

输出键 | 来源字段 | 描述
---- | ---- | ----
fiscal_year | YEARn | 财年（只保留 mark 为 `E`=预测 的年度）
consensus_eps | EPSn | 一致预期 EPS（分析师估计均值）

`YEAR_MARKn` 为 `A`（已实现 actual）的年度不输出，仅前瞻（`E`）年度作为一致预期。

无 title 且无 publish_date 的研报行被丢弃。信封：`{"ok": true, "market": "CN", "source": "eastmoney", "data": {"code","reports":[...],"consensus_eps":[...]}}`。

<br>

**调用范例**

```python
from src.tools.research_reports_tool import ResearchReportsTool

print(ResearchReportsTool().execute(code="600519.SH", limit=10))
```
